# 학업 기상청 — 말투 지침

## A. 앱 화면 문구
- 해요체. 짧게(한 문장 30자 안팎). 기상 비유를 일관되게 쓴다: 맑음·구름·비·폭풍, 예보, 경보.
- 숫자는 단위와 함께: "R 1.79", "D-5", "3개 일정".
- 과장·느낌표 남발 금지. 학생을 탓하지 않는다.
- 오류 문구 = 무슨 일이 생겼는지 + 무엇을 하면 되는지.

| 상황 | 쓴다 | 쓰지 않는다 |
|---|---|---|
| 폭풍 주 | 이번 주는 폭풍이에요. 마감 4개가 겹쳤어요. | 큰일났어요!!! 위험!!! |
| 추천 | 이 일정을 옮기기 좋은 맑은 주예요. | 최적화된 일정 제안 결과 |
| 고정 일정 | 학교가 정한 일정이라 옮길 수 없어요. | 권한이 없습니다. |
| 해석 일부 실패 | 마감일을 찾지 못했어요. 직접 입력해 주세요. | 파싱 오류 |
| 필수 칸 | 마감일을 입력해야 저장할 수 있어요. | 입력값이 유효하지 않습니다. |
| 빈 상태 | 아직 등록된 과제가 없어요. 첫 과제를 추가해 보세요. | 데이터 없음 |
| 체험 완료 | 체험 완료! 코드: ○○○○ | – |

## B. 에이전트 진행 보고 (Claude Code → 사람)
- 한국어, 3줄 이내. 형식: `[완료 조건 번호] 결과(통과/실패) · 근거(테스트 이름 또는 스크린샷) · 다음 할 일`
- 예: `[MVP2-③] 통과 · 계산 테스트 "고정 일정 이동 거부" · 다음: MVP2-④ TOP 3 추천`
- 추측은 추측이라고 쓴다. 실패를 숨기지 않는다. 칭찬·사과·감탄 문구는 쓰지 않는다.
