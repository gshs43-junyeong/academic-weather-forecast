# 학업 기상청 — 날씨 애니메이션 지침

## 0. 핵심 원칙: 날씨가 곧 경고 단계다
맑음(금빛) → 구름(무채색) → 비(주황 경고) → 폭풍(빨강 위험). 단계가 오를수록 색이 따뜻하고 진해지며, 움직임이 빠르고 거칠어진다. 맑음은 "진짜 맑아 보여야" 하고, 폭풍은 "한눈에 위험해 보여야" 한다. 두 끝의 대비가 이 서비스의 첫인상이다.

## 1. 애셋 사용법
`public/weather/` 에 이미지로 제공된다(코드 아님). **아이콘은 다시 그리지 말고 이 파일을 그대로 쓴다.**
| 파일 | 형식 | 용도 |
|---|---|---|
| sunny.webp · cloudy.webp · rain.webp · storm.webp | 투명 배경 애니메이션 WebP, 256×256, 무한 반복 | 사이트 기본 |
| *.gif | 흰 배경 GIF | WebP 미지원 환경·발표 자료 |
| preview.gif | 네 날씨 비교 | 참고용 |

이미지 태그로 넣고, 대체 텍스트에 날씨 이름(맑음·구름·비·폭풍)을 적는다.
카드 48px, 상세 패널 120px, 첫 화면 히어로 160px. `prefers-reduced-motion: reduce`이면 카드 CSS 애니메이션을 끄고(§3 움직임 기준), 아이콘은 GIF·WebP의 첫 프레임을 PNG로 뽑아 둔 정지 이미지로 바꾼다.

## 2. 각 날씨 장면 묘사 (아이콘이 실제로 이렇게 움직인다)
### 맑음 — 주기 4초, 밝고 햇빛이 쏟아지는 느낌
- 해: 중심은 흰색에 가깝게 빛나고 가장자리로 갈수록 금색(#FFC83A)→주황(#FF9E00). 왼쪽 위에 흰 하이라이트.
- 후광: 해를 둘러싼 큰 노란 빛무리가 4초 주기로 1.0→1.12배 커지며 밝아졌다 돌아온다(숨 쉬는 빛).
- 광선: 길고 짧은 광선 12개가 번갈아 있고 4초에 30°씩 천천히 회전.
- 햇살 기둥: 해 아래로 부채꼴 빛줄기 5개가 쏟아지고, 각각 다른 타이밍으로 밝기가 25%↔75% 일렁인다.
- 반짝임: 주변 4곳에서 작은 십자 별이 번갈아 반짝(커졌다 회전하며 사라짐).
### 구름 — 주기 4초, 차분한 정지 상태
- 흰색→연회색 그라데이션의 부드러운 구름. 위쪽에 하이라이트, 아래쪽 음영, 얇은 흰 테두리 반사광, 바닥 그림자.
- 뒤의 작은 구름과 앞 구름이 서로 반대로 ±1.5px 흘러 입체감. 아래쪽에 바람 한 줄기가 나타났다 사라짐.
### 비 — 주기 4초(빗방울 1초), 주황 경고
- 회색 비구름, 구름 아랫면이 주황빛으로 물듦.
- 주황 빗방울 6개(위는 투명, 아래는 #F08A2C)가 서로 다른 타이밍으로 떨어지고, 바닥에 닿는 순간 작은 물튀김이 퍼진다. 바닥에 주황 물웅덩이 반사.
### 폭풍 — 주기 3초(빗방울 0.75초), 빨강 위험
- 검붉은 먹구름: 위 #B4485A → 가운데 #6E1C2A → 아래 #2A070D. 구름이 미세하게 떨린다.
- 붉은 비 7줄기가 바람에 14° 기울어 빠르게 떨어지고, 바닥에 붉은 물튀김.
- 번개: 3초 중 1.77~1.89초, 2.07~2.16초 두 번 번쩍(흰색→연노랑→주황 번개, 붉은 외곽 발광, 갈라지는 가지).
- 번개가 칠 때 **구름 안쪽이 분홍빛으로 밝아지고, 아이콘 주변 전체가 붉은 빛무리로 확 물든다**(평소 12% → 번쩍 순간 100%).

## 3. 사이트 UI 일관성 — 방향성
아이콘과 화면이 하나의 세계처럼 보이도록, 본선에서 에이전트가 아래 방향대로 스타일을 직접 정의한다.

**색 체계**
- 날씨 색은 네 단계로만 쓴다: 맑음 = 따뜻한 금빛(밝은 크림색 배경), 구름 = 차분한 회색(연회색 배경), 비 = 주황(연한 살구색 배경), 폭풍 = 선명한 빨강(연분홍 배경 + 깊은 검붉은색 보조).
- 이 색들은 한 곳에 변수로 모아 두고 카드·배지·차트·타임라인이 모두 같은 값을 참조한다. 빨강은 폭풍 외 용도로 쓰지 않는다.
- 아이콘 이미지의 실제 색(맑음 금색·주황, 비 주황, 폭풍 검붉은 구름과 붉은 비)에 맞춰 고른다.

**카드 연출 (아이콘과 박자를 맞춘다)**
- 맑음 카드: 아이콘의 후광과 같은 4초 주기로 금빛 그림자가 은은하게 숨 쉰다. 밝고 가벼운 느낌.
- 구름 카드: 움직임 없음. 대비를 위해 일부러 조용하게 둔다.
- 비 카드: 주황 테두리. 움직임 없음 또는 아주 약하게.
- 폭풍 카드: 빨간 굵은 테두리. 아이콘의 번개와 **같은 3초 주기, 같은 순간(1.77초·2.07초 무렵)**에 카드 배경과 그림자가 붉게 번쩍인다. 여러 폭풍 카드는 시차 없이 동시에 번쩍여 "학교 전체에 폭풍이 친" 느낌을 준다. R 숫자도 빨간색.

**상태 변화 연출**
- 날씨가 좋아지면 카드가 살짝 떠올랐다 내려오고, 나빠지면 좌우로 짧게 흔들린다.
- "폭풍 → 비" 배지는 바뀐 뒤 날씨의 색으로, 아래에서 떠오르듯 나타났다가 3초 뒤 사라진다.
- 드래그 중인 막대는 살짝 커지고 그림자가 생긴다. 고정 일정은 놓는 순간 원래 자리로 튕기듯 돌아간다.

**움직임 기준**
- 부드럽게 감속하는 곡선을 기본으로, 튕김은 고정 일정 거부에만 쓴다.
- 위치·크기·투명도·그림자만 움직여 끊기지 않게 한다.
- 기기의 '움직임 줄이기' 설정이 켜져 있으면 모든 반복 연출을 끈다.

## 4. 결정적 장면: 폭풍 → 비 (교사가 마감을 옮긴 직후)
| 순서 | 연출 | 시간 |
|---|---|---|
| 1 | 재계산(0.5초 이내) | – |
| 2 | R 숫자 카운트(예 1.79 → 1.34), 빨강→주황으로 색 전환 | 400ms ease-out |
| 3 | 아이콘 storm.webp → rain.webp 크로스페이드, 카드 배경·테두리 빨강→주황 | 300ms |
| 4 | 카드가 살짝 떠오름 | 250ms |
| 5 | 배지 "폭풍 → 비" 등장, 3초 후 페이드 아웃 | 200ms |
나빠지는 경우(비 → 폭풍)는 4번 대신 좌우 흔들림, 그리고 첫 번쩍임이 즉시 한 번 일어나게 카드 애니메이션을 재시작한다.

## 5. 기타
- 첫 진입: 카드가 주 순서대로 30ms 간격 페이드 인(최대 0.6초).
- 상세 패널: 오른쪽에서 220ms 슬라이드.
- 성능: 카드 수십 개에 WebP를 동시에 띄워도 되도록 `loading="lazy"`와 `decoding="async"`를 쓴다. 움직임은 위치·크기·투명도·그림자만 쓴다.

## 6. 배경 영상과 아이콘의 관계
- 배경 영상(public/video, SPEC.md 5장)은 화면 전체의 분위기, 아이콘(public/weather)은 카드 속 정보다. 둘은 같은 날씨 색 체계를 쓴다.
- 배경 영상의 번개(1.6·1.9·3.7초, 5초 반복)와 아이콘의 번개(3초 주기)는 박자가 다르다. **카드의 붉은 번쩍임은 아이콘 박자에 맞춘다.** 배경은 따로 흐르게 둔다.
- 폭풍 → 비 장면(§4)에서는 3번 아이콘 교체와 동시에 배경 영상도 bg-storm → bg-rain으로 0.6초 교차 전환한다. 숫자 카운트가 끝나는 순간 배경 전환도 끝나도록 맞춘다.
- 배경 위에는 항상 가독성 막과 유리 카드가 있다(weather-design 스킬). 배경이 밝아도 글자는 카드 안에서 읽혀야 한다.
