# 학업 기상청 — 마감 폭풍 예보 시스템

시험, 수행평가, 연구활동, 대회, 입시 일정을 하나의 **부하 지수**로 환산해 한 학기 18주를 학년별 **주간 날씨**로 예보하는 웹앱입니다. 교사가 마감을 옮기면 날씨가 그 자리에서 다시 계산됩니다.

Forecast Loop 팀 · 2026 경남과학고 루프랩 랄프톤(Code for Good) 참가작

## 무엇을 할 수 있나요

| 화면 | 누가 | 하는 일 |
|---|---|---|
| 기상 지도 | 학생·교사 | 학년을 고르면 18주가 맑음·구름·비·폭풍 카드로 보입니다. 카드를 누르면 일별 부하와 어떤 일정이 그 주를 무겁게 만들었는지 나옵니다. [달력] 보기에서는 날짜별 날씨를 봅니다. |
| 타임라인 | 교사 | 일정 막대를 끌어 마감을 옮기면 모든 주의 날씨가 다시 계산되고 "폭풍 → 비" 같은 전후 배지가 붙습니다. 막대를 누르면 옮기기 좋은 맑은 주 TOP 3가 나옵니다. 시험·축제 같은 고정 일정은 잠겨 있습니다. |
| 일정 등록 | 학생·교사 | 공지문을 붙여 넣으면 일정명·유형·난이도·마감일·대상 학년이 자동으로 채워지고, 근거가 된 부분에 밑줄이 그어집니다. 교사가 고른 마감일이 폭풍을 만들면 저장 전에 경고와 맑은 주 추천이 뜹니다. 학생이 저장하면 '제보', 교사가 저장하면 '확정'입니다. |
| 플래너 | 학생 | 내가 참가하는 대회·연구·동아리만 반영한 개인 기상도를 보고, 개인 과제를 추가해 타임라인에서 옮겨 봅니다. 다음 폭풍까지 남은 날과 시작 순서를 알려 줍니다. |
| 학년 비교·리포트 | 교사 | 세 학년의 기상도를 같은 시간축에 겹쳐 보고, 다음 4주 예보를 한 장으로 복사하거나 인쇄합니다. |

## 날씨는 이렇게 계산해요

1. 일정마다 **무게 w**, **준비 일수 L**, **참여율 p**가 있습니다. 시험이 가장 무겁고, 연구활동, 탐구대회·올림피아드, 수행평가, 일반대회 순입니다.
2. 무게는 마감 전 L일 동안 **마감에 가까울수록 커지는 삼각형**으로 나뉩니다. 하루 부하는 그날 걸친 모든 일정의 (w × p × 그날 몫)의 합입니다.
3. 월요일부터 일요일까지 더한 값이 **주간 부하 W**, 학기 평균으로 나눈 값이 **날씨 지수 R**입니다.

| R | 날씨 |
|---|---|
| 0.7 미만 | 맑음 |
| 0.7 이상 1.15 미만 | 구름 |
| 1.15 이상 1.6 미만 | 비 |
| 1.6 이상 | 폭풍 |

폭풍 주 판정, 배지, 추천, 리포트는 주 단위이고, 달력의 날짜 칸만 일 단위(하루 부하 ÷ 하루 평균)로 보여 줍니다. 교사는 난이도와 별개로 일정의 무게를 직접 고칠 수 있습니다.

## 체험 방법

1. [시작하기]를 누르고 학생 또는 교사로 로그인합니다. 체험용 아이디와 비밀번호가 미리 입력돼 있습니다.
2. 1학년 기상 지도에서 12월 첫째 주와 넷째 주의 폭풍을 눌러 원인을 봅니다.
3. 교사로 로그인해 타임라인에서 생명과학 자기평가서 막대를 12/23에서 12/15로 끌어 봅니다. 넷째 주 폭풍이 비로 약해집니다.
4. [일정 등록]에서 자기평가서를 12/23 마감으로 넣어 보면 폭풍 경고와 맑은 주 추천이 뜹니다.
5. 샘플 공지문을 붙여 넣고 [해석]을 눌러 자동 채움을 확인합니다.
6. 3학년으로 바꿔 대학 면접이 몰린 11월 넷째 주 폭풍을 확인하면 체험 완료 코드가 나옵니다.

역할은 로그인할 때 정해지고, 바꾸려면 나가기 후 다시 로그인합니다.

## 데이터와 개인정보

- 일정은 2026학년도 2학기 학사일정, 2027학년도 대학 모집요강, 가정으로 채운 값으로 만든 **데모 데이터**입니다. 실제 이름과 학번은 들어 있지 않습니다.
- 로그인은 체험용입니다. 계정 서버가 없고, 입력한 내용은 **이 브라우저에만** 저장됩니다.
- 공지문 해석은 브라우저 안의 규칙으로만 하며, 외부로 나가는 요청이 없습니다.
- 데스크톱 브라우저 전용입니다(기준 1440×900, 최소 1280×720).
